## 🤝 기여 방법 (Contribution)

더 유용하고 새로운 앱을 추천하고 싶으시다면 언제든 기여해주세요!

1. 이 리포지토리를 **Fork** 합니다.
2. 새 브랜치를 생성합니다. (`git checkout -b feature/NewApp`)
3. `README.md` 파일의 적절한 카테고리에 앱 정보를 추가합니다.
4. 변경 사항을 커밋합니다. (`git commit -m 'Add: 추천 앱 이름 추가'`)
5. 브랜치에 Push 합니다. (`git push origin feature/NewApp`)
6. **Pull Request(PR)**를 생성해 주세요.
